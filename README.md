# График FAWORSHIP

Страница графика служений команды прославления FAWORSHIP: https://faworship.github.io/grafik/

Данных в репозитории нет — страница читает Google-таблицу по ссылке `?sheet=<id таблицы>`. Править могут только редакторы таблицы: вход через Google, запись — Sheets API от имени вошедшего.

`index.html` — собранный файл, руками не править. Исходники и сборка — в закрытом проекте (`prototype/schedule/`, `build.py --live`), выкладка — `tools/deploy_grafik.sh` оттуда.

До 10.11.2026 страница жила в папке `grafik/` репозитория FAWORSHIP/faworship.github.io вместе с ChartSet; история её выкладок перенесена сюда.
